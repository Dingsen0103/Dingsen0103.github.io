# 西语小步

一个为中文母语者设计的西班牙语 A1 入门学习网页应用。

## 打开方式

直接双击 `index.html`，或在浏览器中打开这个文件：

`C:\Users\Administrator\Documents\Codex\2026-05-26\new-chat\index.html`

## 当前功能

- 每日学习：14 天循环课程，每天自动显示不同主题
- 词汇卡片：近百个入门词条，中文、西语、英文对照，并带发音提示
- 播放发音：使用浏览器自带语音合成播放西班牙语
- 小测验：根据当天课程和错题自动生成
- 错题复习：答错的表达会自动保存
- 本地进度：掌握记录和错题保存在浏览器 `localStorage`

## 学习建议

每天只做一轮：先听，再跟读，再测验。前几天不需要背语法，先把常用句子说顺。
